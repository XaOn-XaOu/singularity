## Where mine is better

| Topic | mine | claude | Why |
| --- | --- | --- | --- |

## Where claude is better

| Topic | claude | mine | Why |
| --- | --- | --- | --- |
| ESLint ignores | `dist/`, `coverage/`, `.turbo/` | `dist/` only | Vitest coverage writes `.js` report files into each package's `coverage/`, and `eslint .` would lint them. |
| Plain `.js` files | Type-aware rules off (`disableTypeChecked`) | Type-aware rules apply to every file | The first linted `.js` file, such as a config file, would fail with "not found by the project service". |
| pnpm root check | Kept | Off (`ignoreWorkspaceRootCheck: true`) | The check stops `pnpm add x` from silently going to the root when you meant a package. |

## Trade-offs (neither is wrong)

| Choice | claude | mine | Trade-off |
| --- | --- | --- | --- |
| Minimum Node | 24, with `@types/node` 24 | 26, with `@types/node` 26 | Wider support vs newest features. With 26, CI (1.14) and Docker (1.15) must use 26 too. |
| ESLint config file | `eslint.config.js` + root `"type": "module"` | `eslint.config.mts` + `jiti` | No extra package vs a type-checked config file. |
| Lint presets | `strictTypeChecked` + `stylisticTypeChecked` | `strictTypeChecked` | The stylistic preset adds consistency rules; a matter of taste. |
| Export style | `export const PACKAGE_NAME` | `const` + `export { PACKAGE_NAME }` | Export next to the code vs the public surface listed in one place. Same compiled output. |
| Placeholder files | Comment naming the task that replaces each one | Bare `export {}` | Explains why the file is empty vs can't go stale. |
| Turbo `dev` task | Not yet | Defined | Add it with the first dev server vs ready for 1.3. |

## A gap in both

- **Turbo `inputs` with `.env*`:** commented out in mine, missing in claude. `.env` is git-ignored, so Turbo doesn't notice when it changes. Once Vite reads `VITE_*` values (task 1.9), a changed `.env` would still give a cached, stale build. Add `"inputs": ["$TURBO_DEFAULT$", ".env*"]` in 1.2, when `.env` files first appear.

## Lessons

- **A generator brings decisions you didn't make.** From `create-turbo`: `ui: tui`, `.next` outputs, the `check-types` name, the starter README, `.npmrc` and Next.js `.gitignore` lines. Its 55 starter files were deleted in the 1.1 commit. Read every generated line as if you wrote it.
- **A green run that executed nothing isn't green.** Read the task count, not just the exit code.
- **Order matters in configs** (ESLint, `.gitignore`): the last matching entry wins.
- **Run `pnpm lint` right before every commit.** The README newline slipped in after the last lint.
